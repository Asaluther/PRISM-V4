# 流式适应 demo 报告（GOAL V6#4，prequential「边用边学」协议，2026-09-11）

> 数据：`streaming_demo.json` · 脚本：`streaming_demo.py`
> 协议：用户数据 8 批 × 256 token 逐批到达；每批**先评估**（在线预测分，模型尚未见过它）
> **再适应**（60 步 @ lr1e-4，冻结 emb+前6层——forgetting_calibration arm2 校准值）；
> 一次性通过不重复 epoch。对照 = 冻结基线对同一流逐批的 PPL。

---

## 主结果：跨域冷启动流（WT 公平 checkpoint 对 → TS 用户流）

| 指标 | PCN | Transformer |
|---|---|---|
| 在线增益（适应 vs 冻结，批 1-7 均值） | **+24.0%**（2199.7→1671.4） | **-80.9%**（2221.6→4017.9） |
| 流末用户 held-out vs 冻结 | **+27.8%**（2392→1728） | **-183.8%**（2257→6406） |
| 累积 ΔW | 0.599 | 1.120（**1.87×**，权重约束再现） |
| 流末 TS 通用 PPL | ~1300-1600 | ~5200（批7 爆至 12470 在线 PPL） |

**判定：真实流式（一次性、逐批、无早停）下「边用边学」对 PCN 成立、对 TF 反向**——
TF 对每个 256-token 小批过拟合（末批在线 PPL 12470），家域 WT 也漂到 3902；
PCN 在线 PPL 稳定低于冻结线，家域漂移小一个量级（1587）。

## 域内对照流（TS checkpoint 对 → TS 用户流）

| 指标 | PCN | TF |
|---|---|---|
| 在线增益 | **-189.2%**（19.0→55.0） | **-209.4%**（17.0→52.6） |

**判定：已收敛域内流式微调双输**——60 步 × 256 token 的每批预算对收敛模型是纯破坏，
与遗忘基准的「域内无适应空间」结论在流式形式下互证。**边界结论：流式学习仅在
跨域/冷启动场景有效，域内应冻结。**

## 与既有结果的关系

- 单发批量适应（demo 修正口径）：PCN +58.5% vs TF +5.4%
- 流式一次性适应（本报告）：PCN +24.0% vs TF -80.9%
- 两者同向；流式下 TF 更差的原因：每批 256 token 重复 60 步 → 逐批过拟合累积
- ΔW 约束第三场景再现（1.87×，与公平复核 1.91×/1.55×-1.77× 一致）

## 边界与后续

- 每批预算固定 60 步（批量模式校准值）；TF 的流式最优每批步数应更低——预算扫描留作后续
- 批间难度方差大（单批 PPL 波动），结论以 7 批均值口径为准
- 8 批 × 256 token = 2K token 流；更长流的漂移累积未测
